Veylo 2.4.7 · Windows x64

双击 Veylo-2.4.7-Setup-x64.exe。直接点击「安装」使用默认位置，或点击「浏览」选择其他磁盘中的安装文件夹，例如 D:\Veylo。安装器会自动下载并校验 YouTube、X 和哔哩哔哩组件，并按所选路径配置浏览器。

安装完成后，点击「打开扩展管理页」。开启「开发者模式」，选择「加载已解压的扩展程序」，粘贴安装器复制的文件夹路径，再确认。每个要使用的浏览器加载一次。之后点击工具栏的 Veylo 图标，或按 Alt+Shift+V。

第一次安装需要能访问 GitHub，下载约 246 MiB，建议保留 2 GB 空间。下载中断时在安装器里点击「重试」。默认安装目录是 %LOCALAPPDATA%\Veylo。扩展安装在所选目录下的 app-2.4.5\extension。

新安装默认保存到安装目录下的 Downloads。可以在扩展里选择其他保存位置。切换安装目录后，在浏览器中用新版安装器复制的扩展路径加载一次。

需要登录的视频须用自己的账号。从安装完成页的「打开下载器登录」选择平台。平时无需打开下载器窗口。

更新组件时，在 Windows 开始菜单打开「Veylo 安装与更新」，选择「组件更新」中的「检查并更新兼容组件」。可开启每次打开管理器时的自动更新。yt-dlp 可以单独更新或恢复随包版本。FluentYTDL 和 Bili23 通过 Veylo 兼容验证后才会切换。

普通 Windows 上的 Chrome、Edge 不允许普通 Setup 静默加载未上架扩展。安装程序未签名。请从 Veylo 的 GitHub Release 获取，发布页的 SHA256SUMS.txt 可核对文件。

原始 Setup EXE 适合转发。安装目录随后会生成个人配置、下载记录和媒体，请把这些文件留在自己电脑上。
